# SoulWoods

Simple round-based Python game built with `tkinter` / `customtkinter`
A small GUI game where you fight monsters in consecutive rounds.
After each win, you pick an upgrade and continue until you die.

## Gameplay

* **Attack** → starts combat (order based on speed)
* **Guard** → defensive option
* Win → choose upgrade (HP / Speed / Damage)
* Lose → game over
